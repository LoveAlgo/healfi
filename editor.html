Connect to GitHub

The editor saves directly to your repository, so it needs an access key. It is stored only in this browser.

  1. Open GitHub → new fine-grained token.
  2. Give it a name like “Healfi editor” and choose an expiration date.
  3. Under Repository access, choose Only select repositories and pick healfi.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it and paste it below.

Change this when you move to your new domain, for example https://healfi.net/

Find & replace on every page

Useful for things that repeat on all pages, like the menu, footer or sidebar. It searches the pages’ HTML, so you can paste a piece of code as well as plain text. All changes are saved together in one step.
